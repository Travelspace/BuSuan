# 传统命理文化研究工具 (BuSuan)

一个功能完整的传统命理文化研究网页工具，仅用于个人本地学习使用。包含信息填写、八字排盘、紫微斗数、运势分析、姓名测试、择吉日、六爻测算等功能。

🌐 **在线演示**: https://travelspace.github.io/BuSuan/

## 🎯 项目特点

- 📝 **信息填写** - 统一管理姓名、性别、出生地、出生日期等个人信息，各模块自动读取
- 🏮 **八字排盘** - 基于出生时间计算八字四柱命盘，含十神、五行、纳音、藏干、大运流年
- ⭐ **紫微斗数** - 排布紫微斗数十二宫命盘，含主星、辅星、四化飞星及宫位详解
- 📊 **运势分析** - 八字宏观趋势 + 紫微微观分析双标签页，流年评分与12宫位详情
- ✍️ **姓名测试** - 八字派为主、卦象派为辅、五格作参考：汉字五行分层查询、卦象起卦与体用分析、八字喜用神匹配、综合评分（八字60%/卦象25%/五格15%）
- 📅 **择吉日** - 黄历宜忌查询、吉日筛选、八字个性化推荐
- ☯️ **六爻测算** - 手动摇卦/时间起卦，本卦、互卦、变卦及体用生克分析
- 🌐 **中英文切换** - 全站支持中英文自由切换，命理术语保留"汉字 (拼音)"格式
- ☀️ **真太阳时校正** - 根据出生地经度与时区自动校正真太阳时，支持全球城市与夏令时
- 🧭 **交互体验** - 测算后个人信息表单自动隐藏/折叠，结果全宽展示；信息未填写时整页引导一键跳转填写或排盘

## 🔧 关键技术实现

### 姓名测试 - 八字派为主、卦象派为辅

姓名测算核心逻辑采用"八字派为主、卦象派为辅"，五格降级为参考信息：

1. **汉字五行分层查询**（`wuxingLookup.ts`）- 四层回退确保覆盖率：
   - 特殊强规则（品字结构：鑫→金、森→木、淼→水、焱→火、垚→土）
   - 本地字典（`wuxingDict.ts`，6773 字五行数据）
   - 部首推断 + `kangxiStrokes` 补充字典
   - 笔画尾数兜底（1/2→木、3/4→火、5/6→土、7/8→金、9/0→水）
2. **卦象起卦**（`guaAnalysis.ts`）- 用康熙笔画起卦：上卦=姓笔画%8、下卦=名总笔画%8、动爻=总笔画%6；体用关系（用生体/体克用/比和等）按五行生克判定；64 卦名与卦辞查 `guaInterpretation.ts`
3. **八字匹配**（`baziMatch.ts`）- 复用 store 已计算的 `baziResult`，逐字五行与喜用神对照计分（喜神+12、用神+15、忌神-10、补缺+5）
4. **综合评分**（`scoreCalculator.ts`）- 八字×0.6 + 卦象×0.25 + 五格×0.15；**姓名测算前必须先完成八字排盘**（未排盘时禁止测算，表单提示并引导前往八字页，不再提供降级模式）
5. **五格参考**（`wugeCalculation.ts`）- 保留原五格数理、三才配置与得分，作为折叠参考信息展示

### 测算流程交互

- **信息未填写** - 八字/紫微/姓名/运势页整页展示「前往填写 / 前往测算」引导空态，一键跳转信息填写或排盘页面
- **测算后** - 出生信息表单自动隐藏（八字/紫微/姓名）或折叠为左侧竖条（六爻），结果全宽展示，顶部提供「重新测算」入口
- **姓名前置** - 姓名测算必须先在八字模块完成排盘
- **运势自动分析** - 八字与紫微排盘完成后，运势分析页自动计算：八字侧复用已算结果、紫微侧缺失时自动排盘

### 时区问题修复

出生日期存储为 `datetime-local` 格式字符串，避免 `toISOString()` 导致的 UTC+8 偏移。

### 真太阳时校正

出生地选择后自动校正真太阳时，八字与紫微排盘均使用校正后的时间：

1. **位置数据** - 中国省市来自 `true-solar-time` 库内置数据，海外城市补充经度与 IANA 时区
2. **时区与夏令时** - 通过浏览器 `Intl.DateTimeFormat`（IANA 时区数据库）将墙上时钟转为绝对 UTC，自动处理夏令时切换（如 America/New_York 的 EST/EDT）
3. **真太阳时计算** - 基于 `true-solar-time` 库（Jean Meeus 天文算法）计算均时差与经度修正：真太阳时 = 标准时 + (经度 - 标准经线)×4 + 均时差
4. **标准经线推导** - 由该时刻实际 UTC 偏移（含夏令时）推出标准经线，确保冬夏自动切换
5. **语言适配** - 切换英文时，省份显示标准英文名，中国城市显示拼音，海外城市显示英文名
